How to Get a Number Row on Your iPhone Keyboard

Options for typing numbers without constantly switching between letters and digits.

By Javokhir, creator of Typez · Published November 13, 2026
Published by Typez, an iPhone keyboard app currently in App Store review.

On the standard English iPhone keyboard, there is no setting that adds a permanent number row above the letters. You can switch with the 123 key, use a press-and-slide gesture for a single digit, or choose a third-party keyboard with a number row. Layouts vary by language, app, and device; the iPad keyboard is different.

Can you add a number row to Apple’s iPhone keyboard?

For the standard English letter layout, Apple does not offer a “show number row” toggle. The number and symbol layout is a separate view, opened with 123. Changing keyboard feedback, predictive text, or one-handed mode does not add another row of keys.

Some apps request a numeric keypad for a phone number, amount, or code. That keypad belongs to that input field; it does not change your letter keyboard everywhere else. Instructions for an iPad’s number gestures also do not necessarily apply to an iPhone.

A faster way to type one number

If you only need an occasional digit, try this with Apple’s standard English keyboard:

  1. In a normal text field, touch and hold 123.
  2. Without lifting your finger, slide to the number you want.
  3. Lift your finger to enter it and return to the letter layout.

For several digits in a row, simply tap 123, type the numbers, and tap ABC to return. The press-and-slide gesture is a useful shortcut, but it is not a persistent number row. Keyboard layouts and gesture behavior can differ, so try it in a note before relying on it in another app.

When a dedicated number row helps

If you frequently mix letters and numbers—street addresses, product names, reference numbers, or dates—a visible row can reduce layout switching. The tradeoff is space: an extra row can take more screen height or require a denser layout.

Use a keyboard that fits the text you write most often. A person who mainly writes messages may prefer a simpler layout; someone repeatedly entering mixed codes may value the extra row more.

How to enable another keyboard

After installing a keyboard app, open Settings → General → Keyboard → Keyboards → Add New Keyboard and select it. Open a text field, touch and hold the globe key, and choose the keyboard. See Typez setup help for the Typez-specific steps.

A third-party keyboard will not appear in every field. iOS uses its own keyboard for secure input and certain phone pads, and an app can disallow custom keyboards. That means a number-row keyboard cannot promise the same layout everywhere.

Do you need Full Access just for a number row?

An extra row of keys does not inherently require network access. Permissions depend on the keyboard and the feature. In Typez, core typing and cursor navigation work without Full Access; optional clipboard functionality requires it because of iOS restrictions.

Review the app’s privacy policy rather than enabling permissions just because a tutorial says to. Typez’s privacy policy explains the difference between typing and clipboard access.

An alternative for numbers you repeat

A number row helps you enter new text. It may not be the quickest answer for an address or reference string you reuse unchanged. Apple’s Text Replacement can expand a shortcut into a phrase; saved text can insert an item you deliberately kept.
